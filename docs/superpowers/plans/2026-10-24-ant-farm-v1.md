# Ant Farm v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A playtest build of the top-down ant-farm toy: a colony digs out a 64 × 64 dirt map, the player squishes ants, paints dirt back, buys five upgrades, and watches the colony grow through four visual tiers.

**Architecture:** All game rules live in plain C# classes (grid, search, colony simulation, economy, save mapping, gesture parsing) that EditMode tests drive directly. Thin MonoBehaviours render the model (one texture for the whole dirt grid, pooled ant sprites), route touch input by mode, and run the juice layer, which only listens to model events. `GameBootstrap` owns the model and ticks it.

**Tech Stack:** Unity 6000.6.0f1, 2D URP, Input System (EnhancedTouch), uGUI, Unity Test Framework (NUnit). Same package set as `/Users/ryoshou/first-hyper-casual`.

**Spec:** `docs/superpowers/specs/2026-10-24-ant-farm-design.md`

- Portrait only; iOS and Android; `Application.targetFrameRate = 60`.
- v1 is a private playtest build: no store listing, privacy labels, crash reporting, or save-versioning guarantees.
- Every gameplay number comes from `TuningConfig` (economy/world) or `JuiceConfig` (feel). Spec values are the defaults. Never hardcode them.
- Spec defaults: map 64 × 64, 10 dirt/tile, base 5 × 5 in the center, 3 starting ants, 0.5 s deposit, tiers at total levels 0/10/30/55 with ant scale 1/1.15/1.3/1.45.
- Code conventions (copied from first-hyper-casual): namespace `Game.<Folder>`, one MonoBehaviour per file, `[SerializeField] private` fields, no `GameObject.Find`/`FindObjectOfType` at runtime, no allocations in `Update` (no LINQ, no string concat; reuse lists).

- Testing (overrides the global 80% / full-TDD rule, same as first-hyper-casual): EditMode tests for pure logic; one PlayMode smoke test; game feel, VFX, and UI look are verified by playing.

## Review Focus

1. **Painting walls ants into a pocket with no path home.** Ants must dig their way out toward the base and never freeze. Test: `Colony_WalledInAnt_DigsOutAndGetsHome` (Task 5).
2. **A fast swipe moves far between two frames.** Every ant and cell along the whole segment is hit, not just the endpoints. Tests: `KillWithin_LongSegment_KillsEveryAntOnIt` (Task 5), `CellsAlong_LongSegment_HasNoGaps` (Task 6).
3. **A second finger lands mid-stroke.** The stroke cancels and becomes a pan/pinch. Lifting one finger never restarts a kill or paint stroke. Tests: `SecondFinger_CancelsStroke_ThenPans` and `LiftingOneOfTwoFingers_DoesNotStartStroke` (Task 6).
4. **Painting onto the base, out of bounds, or a full tile** is a no-op, and ants inside the base are never buried. Test: `Fill_OnBaseOrOutOfBounds_ReturnsFalse` (Task 3).
5. **The save file is corrupt, truncated, or from another map size.** Start fresh, log a warning, never crash. Test: `Decode_WrongGridLength_IsCorrupt` (Task 7).

### Task 4: GridSearch (dig targets and paths)

- Test: `Assets/Tests/EditMode/GridSearchTests.cs`

**Interfaces:**
- Consumes: `DirtGrid` (Task 3).
- Produces: `GridSearch(DirtGrid grid)`. It preallocates its BFS queue, visited stamp array, and parent array at w×h, so a search allocates nothing.
  - `int FindDigTargets(Vector2Int start, int maxCandidates, List<Vector2Int> targetsOut)` runs a 4-neighbour BFS over open cells from `start`. In BFS order it collects distinct non-base dirt cells that touch a visited open cell, up to `maxCandidates`, and returns the count (0 = nothing reachable).
  - `bool FindPathToDig(Vector2Int from, Vector2Int dirtCell, List<Vector2Int> pathOut)` finds the shortest path over open cells, ending at an open 4-neighbour of `dirtCell`. `pathOut` excludes `from`; it is empty if `from` is already adjacent.
  - `bool FindPathHome(Vector2Int from, List<Vector2Int> pathOut)` finds the shortest path over open cells to the nearest base cell, ending on it. The path is empty if `from` is a base cell.
  - `bool IsConnectedToBase(Vector2Int from)`.

### Task 5: Colony simulation

**Files:**
- Create: `Scripts/Runtime/Sim/{AntState,Ant,AntBrain,Colony}.cs`
- Test: `Assets/Tests/EditMode/ColonyTests.cs`, `Assets/Tests/EditMode/PacingBandTests.cs`

**Interfaces:**
- Consumes: `DirtGrid`, `GridSearch`, `GridCoords`, `UpgradeBook`, `Wallet`, `TuningConfig`.
- Produces:
  - `enum AntState { ToDig, Digging, Returning, Depositing, Idle, DiggingOut }`
  - `sealed class Ant { int Id; Vector2 Position; AntState State; int Carrying; Vector2Int Target; float Heading; }` (Heading in radians, for the view). The internal path list and timers stay internal to `Game.Sim`.
  - `Colony(DirtGrid grid, UpgradeBook upgrades, Wallet wallet, TuningConfig cfg, int seed)` starts with `cfg.startAnts` ants at `BaseCenter`.
  - `IReadOnlyList<Ant> Ants`, `int Count`, `int Cap` (= `(int)upgrades.Value(ColonyCap)`), `void Tick(float dt)`.
  - `bool Kill(int antId)` drops the ant's carried dirt and raises `AntKilled`.
  - `int KillWithin(Vector2 a, Vector2 b, float radius)` kills every ant within `radius` of segment a→b and returns how many.
  - `void SetAntCount(int n)` (restore/reset: removes all ants, then spawns n at the base, clamped to Cap).
  - Events: `event Action<Ant> AntKilled` (also raised for burial), `event Action<Ant> AntHatched`, `event Action<int> Deposited` (amount), `event Action<float> TripCompleted` (one-way trip length in tiles).
  - `AntBrain` (internal static): `Step(Ant, float dt, Colony ctx)`.

**Behaviour rules (from the spec, with my calls where marked):**
- **Hatching:** while `Count < Cap`, a timer runs at `Value(HatchSpeed)` seconds per ant, and each ant hatches at `BaseCenter`. When the colony is at the cap, the timer holds at 0.
- **ToDig:** pick a random cell among the first `digCandidates` from `FindDigTargets(antCell)` (seeded `System.Random`), take `FindPathToDig`, and walk cell centre to cell centre at `Value(WalkSpeed)` tiles/s. Before entering each next cell, if it's no longer open, re-plan. If the target is gone (already open), pick a new one.
- **Digging:** `Dig(target, …)` at `Value(DigSpeed)` dirt/s (accumulate fractional dirt) until `Carrying == (int)Value(CarryAmount)` or the tile is empty → Returning.
- **Returning:** `FindPathHome` → walk → **Depositing** for `depositSeconds` → `wallet.Add(Carrying)`, raise `Deposited` and `TripCompleted` → ToDig.
- **Idle:** when `FindDigTargets` returns 0, the ant wanders to random open cells within 3 tiles of the base and re-checks every `idleRecheckSeconds`.
- **Burial:** on `grid.CellChanged`, if a cell becomes non-open and an ant stands in it, kill that ant (spec: painting over an ant buries it).
- **DiggingOut** (my call, Review Focus 1): when `FindPathHome` fails, dig the 4-neighbour dirt cell that minimizes distance to `BaseCenter`, at dig speed. Dirt beyond carry capacity is discarded. Step into the cell once it opens, and repeat until `IsConnectedToBase`, then Returning.
- **Kill:** removes the ant immediately; its carried dirt is lost.

### Task 6: Gesture parsing, brush strokes, camera math

**Files:**
- Create: `Scripts/Runtime/Controls/{PlayMode,GestureEvent,GestureTracker,BrushStroke,CameraMath}.cs`
- Test: `Assets/Tests/EditMode/ControlsTests.cs`

**Interfaces:**
- Produces:
  - `enum PlayMode { Kill, Dirt, View }`. Kill is the default.
  - `enum GestureKind { StrokeBegin, StrokeMove, StrokeEnd, StrokeCancel, Pan, Pinch }`. `readonly struct GestureEvent { GestureKind Kind; Vector2 From; Vector2 To; float Scale; }` holds screen-space positions. Pan uses `To − From` as the delta; Pinch uses `To` as the screen centre and `Scale` as the ratio of finger distance this frame to last frame.
  - `GestureTracker.Step(int touchCount, Vector2 p0, Vector2 p1, List<GestureEvent> eventsOut)` is called once per frame.
    - One finger down from zero → `StrokeBegin(p0)`. A tap is Begin + End, and the action fires on Begin, so taps feel instant.
    - One finger moving → `StrokeMove(prev, p0)`. All fingers up → `StrokeEnd`.
    - A second finger lands during a stroke → `StrokeCancel`. Then, while two fingers are down, emit `Pan` (midpoint delta) and `Pinch` (distance ratio) each frame.
    - After a two-finger gesture, no stroke starts again until the touch count returns to 0.
  - `static class BrushStroke { void CellsAlong(Vector2 fromWorld, Vector2 toWorld, float radius, int w, int h, List<Vector2Int> cellsOut); }` collects every in-bounds cell whose centre lies within `radius` of the segment, with no duplicates. It clears `cellsOut` first.
  - `static class CameraMath`:
    - `float OrthoSizeForTilesAcross(float tiles, float aspect)` = `tiles / aspect / 2`.
    - `float ClampTilesAcross(float tiles, float min, float max)`.
    - `Vector2 ClampCenter(Vector2 center, float orthoSize, float aspect, int mapW, int mapH)` keeps the view inside the map. If the view is larger than the map on an axis, it centres that axis.
    - `Vector2 ZoomAround(Vector2 center, Vector2 focusWorld, float oldOrtho, float newOrtho)` keeps the focus point fixed on screen.
